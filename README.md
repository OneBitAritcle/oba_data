# oba_data
한입 기사(OBA: One Bite Article) **데이터 엔지니어링 레포지토리**입니다.
사용자의 뉴스 소비 및 퀴즈 풀이 데이터를 기반으로,
**자동 수집, 정제, 저장, 분석**이 가능한 실시간 데이터 파이프라인을 구축합니다.
